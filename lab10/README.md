# Лабораторная работа №10: Обработка голоса

Вариант 3: анализатор речи. (свой номер случайно записал не +7, а +8, поэтому не удивляйтесь странной эталонной цепочке и полученным результатам)

## Что сделано
1. Подготовлены записи в `samples` в WAV-формате: `PCM 16 bit`, `mono`, `48000 Гц`
2. Загружается алфавит: цифры `0-9` и слово `плюс`
3. Для `samples/phone.wav` строится спектрограмма с оконным преобразованием Фурье и окном Ханна
4. Запись телефонного номера сегментируется по коротковременной RMS-энергии
5. Каждый сегмент сопоставляется с образцами алфавита
6. Телефонный номер распознается как цепочка символов
7. Считается число ошибок и оценка достоверности

## Поиск сегментов
Словарь заранее ограничен словами `ноль`, `один`, ..., `девять` и `плюс`, поэтому сегменты можно искать по паузам и энергии.

Для сравнения используются спектральные признаки.

## Метод
Спектрограмма строится через STFT:

```text
STFT{x[n]}(m, w) = sum x[n]w[n - m]e^(-jwn)
spectrogram{x[n]} = |STFT{x[n]}|^2
```

Окно Ханна:

```text
w(n) = 0.5 - 0.5 * cos(2*pi*n / (N - 1))
```

Параметры:

```text
длина окна STFT = 30 мс
перекрытие = 67%
шкала частот = логарифмическая
```

Сегментация:

```text
RMS = sqrt(mean(x^2))
```

Сигнал делится на короткие окна по `25 мс` с шагом `10 мс`. Если RMS выше адаптивного порога, участок считается речью. Короткие паузы внутри слова склеиваются, слишком короткие фрагменты отбрасываются.

Сопоставление:
- для каждого слова строится последовательность логарифмических спектральных полос от `80` до `5500 Гц`
- частотные полосы взяты на логарифмической шкале
- сегмент сравнивается с каждым образцом алфавита методом DTW, чтобы учесть разную скорость произношения
- выбирается образец с минимальным расстоянием

Оценка достоверности для сегмента:

```text
confidence = (second_distance - best_distance) / second_distance
```

Итоговая достоверность — среднее по всем сегментам.

## Структура
- `main.py` — код лабораторной
- `samples/*.wav` — WAV-записи алфавита и телефонного номера
- `output/spectrograms/phone_spectrogram.png` — спектрограмма телефонного номера
- `output/segmentation/phone_segments.png` — график сегментации
- `output/segments/*.wav` — вырезанные сегменты
- `output/tables/recognition.csv` — таблица распознавания
- `output/reports/report.txt` — краткий текстовый отчет
